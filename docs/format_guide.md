# Format Guide

This page describes the various log formats supported by ntpstats.

ntpstats supports parsing:
- `loopstats`, `peerstats`, and `rawstats` from `ntpd` and `NTPsec`
- `tracking`, `measurements`, and `statistics` from `chrony`
- CSV files with `timestamp` and `offset` columns
- PTP logs from `linuxptp`
- and more!
