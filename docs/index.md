# ntpstats Documentation

Welcome to the documentation for **ntpstats**.

ntpstats is a tool for NTP / network-time offset, delay and frequency-stability analysis (ADEV, MDEV, TDEV, HDEV, MTIE) with a lightweight web UI.

Please see the [Format Guide](format_guide.md) for information on log formats, the [Statistics Primer](statistics_primer.md) for a primer on the stability and network metrics, and the [API Reference](api_reference.md) for details on the programmatic API.
