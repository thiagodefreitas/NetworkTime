# Cross-validation

ntpstats performs rigorous cross-validation to guarantee the correctness of its mathematical implementations:

1. **Independent Reference Deviations**:
   The `test_stability.py` test suite cross-validates ADEV, MDEV, TDEV, HDEV, and MTIE against a pre-computed JSON dataset (`reference_deviations.json`) generated by independent libraries (e.g., allantools) for the same input phase data (`reference_phase.txt`). This ensures ntpstats does not have regressions against established python libraries.

2. **Stable32 and Long-term Logs**:
   The algorithms mirror established methodologies and can be validated against Stable32. The implementation of confidence intervals and gap-aware resampling complies rigorously with W. J. Riley's "Handbook of Frequency Stability Analysis". Real long-term logs from GNSS-disciplined hosts are often utilized during development as ground truth against chrony and ntpd offsets to verify that standard estimators function smoothly with long real-world datasets.

These validations happen in standard pytest runs in CI.
