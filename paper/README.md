# Paper

`paper.md` and `paper.bib` are a draft software paper for the
[Journal of Open Source Software](https://joss.theoj.org/) (#38). The *Paper* workflow builds the
PDF on every change to this folder (download it from the workflow run's artifacts).

The paper follows the current JOSS structure: Summary, Statement of need, State of the field,
Software design, Research impact statement and AI usage disclosure (750-1750 words).

Before submitting:

1. write the **AI usage disclosure** (which tools were used, for what, and how the output was
   reviewed); only the author can make this statement;
2. add concrete **evidence of use** to the research impact statement (studies, theses,
   deployments, courses or citations, with links);
3. check **eligibility**: JOSS expects public development spread over more than six months,
   not a single burst, with signs of research use. Most of the current work dates from
   September-October 2026, so a submission from about April 2027 is realistic;
4. make sure the release to review is archived on Zenodo (the DOI goes in the submission form);
5. re-read the paper against the current release and the JOSS review checklist.
