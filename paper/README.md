# Paper

`paper.md` and `paper.bib` are a draft software paper for the
[Journal of Open Source Software](https://joss.theoj.org/) (#38). The *Paper* workflow builds the
PDF on every change to this folder (download it from the workflow run's artifacts).

Before submitting:

1. add the author's affiliation in the front matter (the ORCID is in);
2. make sure the release to review is archived on Zenodo (the DOI goes in the submission form);
3. re-read the statement of need against the current release and the JOSS review checklist.
